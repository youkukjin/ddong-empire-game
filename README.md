# 똥제국의 위기

직접 만든 동화책 「똥제국의 위기」를 바탕으로 한 어린이용 안드로이드 게임이에요.
엔진은 **Godot 4.3 (GDScript)** 를 써요.

## 지금 들어 있는 것

| 항목 | 내용 |
| --- | --- |
| 화면 | 세로 화면(720×1280 기준), 여러 화면 크기에 맞춰 늘어나요 |
| 조작 | 터치 (PC에서는 마우스 클릭이 터치처럼 동작해요) |
| 타이틀 화면 | 제목 「똥제국의 위기」와 **시작하기** 버튼 |
| 게임 화면 | 1장 '등장' 자리 (지금은 "준비 중이에요" 안내와 **처음으로** 버튼) |
| 안드로이드 | 내보내기 설정(`export_presets.cfg`) 포함, 안드로이드 뒤로 가기 버튼 지원 |

## 폴더 구조

```
project.godot            프로젝트 설정 (세로 화면, 터치, 모바일 렌더러)
export_presets.cfg       안드로이드 내보내기 설정
icon.svg                 임시 아이콘
scenes/title/            타이틀 화면
scenes/game/             게임 화면 (지금은 자리만 있어요)
tests/smoke_test.gd      화면 이동 자동 확인
```

## PC에서 실행하고 확인하기

1. [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/)을 내려받아요. (표준 버전, .NET 아님)
2. Godot를 열고 **가져오기(Import)** 를 눌러 이 폴더의 `project.godot`를 골라요.
3. 오른쪽 위 **▶ (F5)** 를 눌러요.
4. 확인할 것
   - 세로로 긴 창에 「똥제국의 위기」 제목이 살짝 통통 튀어요.
   - **시작하기**를 누르면 "1장 '등장' 준비 중이에요" 화면으로 가요.
   - **처음으로**를 누르면 타이틀로 돌아와요.

### 자동 확인 (선택)

```bash
godot --headless --path . -s tests/smoke_test.gd
```

`모든 확인 통과`가 나오면 성공이에요.

## 안드로이드 폰에서 실행하기

1. Godot 메뉴 **편집기 → 편집기 설정 → 내보내기 → Android**에서 Java SDK(OpenJDK 17)와 Android SDK 경로를 넣어요.
   자세한 방법은 [공식 문서](https://docs.godotengine.org/ko/4.x/tutorials/export/exporting_for_android.html)를 봐요.
2. **편집기 → 내보내기 템플릿 관리**에서 4.3 템플릿을 내려받아요.
3. 폰에서 **개발자 옵션 → USB 디버깅**을 켜고 PC에 연결해요.
4. 오른쪽 위에 생기는 **안드로이드 아이콘(원격 실행)** 을 누르면 폰에서 바로 실행돼요.
   APK 파일이 필요하면 **프로젝트 → 내보내기 → Android → 프로젝트 내보내기**를 눌러요.

> 디버그 실행은 Godot가 만드는 디버그 키로 서명돼요. 구글 플레이에 올릴 때는 따로 릴리스 키가 필요해요.
> 키 파일(`*.keystore`)은 저장소에 올리지 않도록 `.gitignore`에 넣어 두었어요.

## 참고

- 한글 글꼴은 아직 따로 넣지 않았어요. 안드로이드와 윈도우에서는 기기의 한글 글꼴로 보여요.
  (**제안**) 동화책 느낌에 맞는 둥근 한글 글꼴을 고르면 프로젝트에 넣을게요.
- 색은 동화책 분위기를 해치지 않도록 크림색 배경과 갈색 버튼으로 임시로 정했어요. 그림이 준비되면 바꿔요.
- 앱 패키지 이름은 임시로 `com.ddongempire.game`이에요. 플레이 스토어에 올리기 전에 정하면 돼요.
- 출판이나 상업적 배포에 관한 판단은 전문가 확인이 필요해요.
