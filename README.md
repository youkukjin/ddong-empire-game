# 똥제국의 위기

직접 만든 동화책 「똥제국의 위기」를 바탕으로 한 어린이용 안드로이드 게임이에요.
엔진은 **Godot 4.3 (GDScript)** 를 써요.

## 지금 들어 있는 것

| 항목 | 내용 |
| --- | --- |
| 화면 | **가로 화면**(1280×720 기준). 비율이 다른 기기에서는 위아래나 양옆에 여백이 생겨요 |
| 조작 | 터치 (PC에서는 마우스가 터치처럼 동작해요) |
| 타이틀 화면 | 제목과 **시작하기**, **장 고르기** 버튼. 1장을 별 3개로 깨면 **어려움 모드** 버튼이 나타나요 |
| 장 고르기 | 1~8장 칸. 깬 장의 다음 장이 열리고, 칸에 최고 별이 보여요 |
| 1장 '등장' | 이야기 장면 → 대피 플레이 → 드래곤 퇴장 → 결과 화면 → 2장으로 |
| 2장 '준비' | 연습 네 가지(아령 들기, 검, 사슬 무기, 구르기) → 결과 화면 → 3장 예고 |
| 3장 '구멍 탐험' | 굴 속 달리기(뛰기, 숙이기, 갈림길 고르기) → 본거지 입구 → 결과 화면 |
| 4장 '성벽 돌파' | 벽돌 성벽 부수기(검, 초록 소용돌이, 대포알 피하기) → 결과 화면 |
| 5장 '무사들과 대마왕' | 옆에서 보는 싸움: 똥 무사 두 무리 → 똥 대마왕 (1차 보스) → 결과 화면 |
| 6장 '재도전' | 일주일 준비(행동 18번: 훈련·모험·백성 돕기·대장간·작전 회의) → 7일째 드래곤 2차전 (2차 보스) |
| 7장 '각성과 결말' | 다시 일어난 드래곤과 마지막 싸움 → 똥의 신으로 각성해 완전히 물리치기 |
| 8장 '평화' | 집 고치기, 불씨 끄기, 백성 데려오기 (시간 제한·실패 없음) → 해가 뜨는 끝 장면 → 모은 별 → 끝 |
| 안드로이드 | 내보내기 설정(`export_presets.cfg`) 포함, 뒤로 가기 버튼 = 멈춤 |

처음부터 끝까지(1~8장) 할 수 있어요. 깬 장의 다음 장이 열리고, 8장 끝에는 모은 별을 보여주고 타이틀로 돌아가요.

그림은 아직 없어서 모두 **임시 도형**이에요 (보라색 드래곤, 똥 왕자, 막대 사람 백성, 무사, 대마왕, 장마다 배경).

## 1장 '등장' 규칙

[1장 기획안](https://claude.ai/artifact/WJhDciA1xNwsJyKAkchmTw)대로 만들었어요. 숫자는 모두 `scenes/chapter1/stage1_rules.gd` 한 파일에 모여 있어서 거기만 고치면 바뀌어요.

| 항목 | 규칙 |
| --- | --- |
| 목표 | 3분 안에 백성 15명 중 **12명 이상**을 돔 대피소로 |
| 백성 구하기 | 백성을 누른 채 돔까지 **끌기**. 불 위로는 지나갈 수 없어요 |
| 불 끄기 | 빈 곳에서 손가락으로 **쓱 쓸기**. 한 번에 3개 이상 끄면 **콤보 별 +1** |
| 드래곤 코 | 15초마다 드래곤이 입을 벌려요. 코가 빛나는 **1.5초 안에 톡** → "에취!" 하고 물러나요 |
| 보라색 줄기 | 땅에 경고 점선이 먼저 보이고 줄기가 나가요. 지나간 자리에 불이 붙어요 |
| 하트 | 3개. 백성이 줄기에 맞거나, 코를 놓치면 1개 줄어요 (코를 놓치면 백성 1명이 겁을 먹고 도망가요) |
| 불 번짐 | 5초 동안 안 끄면 옆으로 번져요 |
| 난이도 | 처음 20초 연습(줄기 없음, 불 2개) → 초반(4초마다, 1초 전 점선, 불 3개) → 8명 구한 뒤 후반(3초마다, 0.7초 전 점선, 훑는 줄기, 불 5개) |
| 별 | 별 3개: 15명 + 하트를 하나도 안 잃음 · 별 2개: 14~15명 · 별 1개: 12~13명 |
| 실패 | 하트 0개, 또는 시간이 끝났는데 12명 미만. 팁 한 줄을 보여 줘요 |
| 중간 지점 | 8명을 구한 순간 저장. 실패하면 **중간부터**로 8명, 하트 3개에서 다시 시작 |
| 도움 켜기 | 3번 연속 실패하면 권해요. 켜면 경고 점선이 1.5초 전에 나와요 |
| 어려움 모드 | 별 3개로 깨면 열려요. 하트 1개, 2분 30초 |
| 멈추기 | 오른쪽 위 **II** 버튼 → 계속 / 다시 하기 / 처음으로 |

### 기획안에 없어서 새로 정한 것 (제안)

- 첫 큰 입은 연습 20초가 끝날 때 나와요. 연습 중에 하트를 잃지 않게 하려고요.
- 줄기에 맞은 백성은 1초 동안 어질어질해서 끌 수 없어요.
- 중간부터 다시 할 때 남은 시간이 1분보다 적으면 1분으로 채워 줘요. 중간부터 한 판은 별 3개가 안 돼요.
- 도망간 백성이 4명이 되면 12명을 채울 수 없어서 바로 실패로 끝나요.
- 이야기 장면 글, 드래곤이 날아가는 퇴장, 똥 왕자가 다짐하는 예고 장면은 기획안의 (제안)을 글로 옮긴 거예요. 작가 확인 전이에요.
- 기록(최고 별, 2장 열림, 어려움 모드 열림)은 기기 안 `user://save.cfg`에 저장돼요.

## 2장 '준비' 규칙

원작 챕터 구성표에는 "똥 왕자가 드래곤을 물리치려고 준비함"까지만 있어서, **연습 종류와 숫자는 모두 제안**이에요.
아령은 원작 그림에 여러 번 나와서 첫 연습으로 골랐어요. 숫자는 `scenes/chapter2/stage2_rules.gd`에 모여 있어요.

| 연습 | 조작 | 통과 / 별 2개 / 별 3개 |
| --- | --- | --- |
| 아령 들기 | 줄어드는 고리가 가운데 원에 맞을 때 **톡** (±0.12초 2점, ±0.25초 1점, 고리 12개) | 12 / 17 / 21점 |
| 검 연습 | 25초 동안 튀어나온 표적을 **톡**. 테두리가 두꺼운 단단한 표적은 두 번 | 12 / 18 / 24개 |
| 사슬 무기 연습 | **꾹 눌러** 힘을 모으고(1.7초), 표적이 초록 줄 위에 올 때 **떼기**. 6번 | 3 / 4 / 6번 |
| 구르기 연습 | 굴러오는 공에 "!"가 뜨면 **쓱 쓸어서** 구르기. 무적 0.4초. 공 10개 | 6 / 8 / 10개 |

- 연습마다 안내 창 → 시작 → 결과예요. 통과 못 하면 그 연습만 다시 해요. 통과한 연습도 "다시 연습"으로 별을 더 받을 수 있어요.
- 장 별: 네 연습 별을 더해서 11개 이상 별 3개, 8개 이상 별 2개, 나머지 별 1개.
- 여기서 익힌 조작(탭 = 검, 길게 눌렀다 떼기 = 사슬 무기, 쓸기 = 구르기)은 5~7장 싸움에서 그대로 써요. (제안)
- 모으기 1.7초와 무적 0.4초는 [6장 설계](https://claude.ai/artifact/NEH9eW3guKY5meedYomZ5t)의 시작 능력치(민첩 10) 값이에요.
- 이야기 글과 3장 예고 글은 제안이에요. 작가 확인 전이에요.

## 3장 '구멍 탐험' 규칙

원작: "일주일 후 준비를 마치고, 수상한 구멍으로 들어가 드래곤의 본거지를 찾음". 원작 그림에 왕자가 검을 들고 구멍에 들어가는 장면이 있어요.
**달리기 방식, 장애물, 갈림길의 보라색 자국(드래곤이 지나간 흔적), 숫자는 모두 제안**이에요. 숫자는 `scenes/chapter3/stage3_rules.gd`에 있어요.

| 항목 | 규칙 |
| --- | --- |
| 달리기 | 왕자가 저절로 달려요. 굴 4구간, 구간마다 빨라져요 (300 → 420) |
| 톡 (또는 위로 쓱) | 뛰어서 바위와 구덩이를 넘어요. 높이 떠 있는 반짝이는 돌도 뛰어야 먹어요 |
| 아래로 쓱 | 숙여서 낮은 천장 밑을 지나가요 |
| 갈림길 | 앞 3구간 끝마다 위·아래 굴. 3초 전부터 보여요. **보라색 자국** 쪽으로 쓸어요. 틀리거나 안 고르면 막다른 길이라 10초를 잃어요 |
| 하트 | 3개. 장애물에 부딪히면 1개 줄고 1초 동안은 다시 안 다쳐요 |
| 시간 | 1분 15초 (쉬지 않고 달리면 약 54초) |
| 별 | 별 3개: 하트 그대로 + 갈림길 모두 맞힘 + 반짝이는 돌 70% 이상 · 별 2개: 하트 2개 이상 · 별 1개: 도착 |
| 실패 | 하트 0개, 또는 시간 끝 |

굴 모양은 판마다 달라져요. 이야기 글과 4장 예고 글("본거지 아래를 단단한 성벽이 막고 있었어요")은 제안이에요.

## 4장 '성벽 돌파' 규칙

원작: "본거지 아래 단단한 성벽을 부숨". 원작 그림에 벽돌 성벽과 대포가 있고, 팔에 사슬로 이어진 무기가 초록 소용돌이를 쏘며 성벽을 부숴요("콰지직").
대포가 누구 편인지는 그림만으로 **확실하지 않아서**, 성벽 위에서 왕자에게 쏘는 것으로 정했어요 (**제안**).
벽돌 수·체력·대포 간격·별 기준 같은 **숫자는 모두 제안**이에요. 숫자는 `scenes/chapter4/stage4_rules.gd`에 있어요.

| 항목 | 규칙 |
| --- | --- |
| 목표 | 벽돌 10줄 × 5층 성벽에서 **나란한 두 줄**을 위부터 아래까지 뚫기 |
| 땅을 톡 | 그쪽으로 걸어가요 |
| 벽돌을 톡 | 아래 두 층은 검으로 1씩 깎아요 (벽돌 체력 3). 멀거나 위층이면 그 앞으로 걸어가요 |
| 꾹 눌렀다 떼기 | 1.7초 모으면 초록 소용돌이가 왕자 위쪽 벽돌을 아래부터 힘 5만큼 부숴요. 줄이 비어 있으면 성벽 위 대포까지 부서져요 |
| 옆으로 쓱 | 구르기 (0.4초 동안 안 다쳐요) |
| 대포 | 3대가 차례로 쏴요. 땅에 빨간 그림자가 1.2초 먼저 보여요. 2.2초마다, 45초 남으면 1.6초마다 |
| 하트 / 시간 | 3개 / 1분 30초 |
| 별 | 별 3개: 하트 그대로 + 30초 이상 남김 · 별 2개: 하트 2개 이상 · 별 1개: 구멍을 뚫음 |

## 5장 '무사들과 대마왕' 규칙 (1차 보스)

원작: "성벽 뒤의 똥 무사들과 똥 대마왕을 물리침". 원작 그림의 무사들과 뿔 달린 대마왕, 가시 달린 무기로 무사를 치는 장면을 참고했어요.
**적의 공격 종류, 숫자, 무사 두 무리 구성, 끝 장면(드래곤의 보라색 광선에 물러남)은 모두 제안**이에요.
끝 장면은 무사들이 쓰러진 뒤 보라색 광선이 왕자에게 떨어지는 그림을 보고 짐작한 거라 **확실하지 않아요**.

싸움 규칙은 5~7장이 함께 쓰는 `scripts/battle/battle_rules.gd`에 있어요.

| 조작 | 하는 일 |
| --- | --- |
| 톡 | 적 가까이면 검(10 피해), 멀면 그쪽으로 걸어가요 |
| 꾹 눌렀다 떼기 | 1.7초 모으면 누른 쪽으로 사슬 무기(20 피해, 520 거리). 무사는 뒤로 밀리고 하던 공격이 끊겨요 |
| 옆으로 쓱 | 구르기. 0.4초 동안 안 다쳐요. 경고가 끝나는 순간 구르면 "아슬아슬!" |

| 적 | 체력 | 공격 (경고 시간) |
| --- | --- | --- |
| 똥 무사 | 40 | 칼 휘두르기 12 (0.9초) |
| 똥 대마왕 | 500 | 뿔 박치기 25 (1.0초, 화면을 가로질러 돌진), 내려찍기 20 (1.0초, 주변). 체력 절반 아래면 무사 둘을 불러요 |

- 왕자 체력 100 (6장 설계 Lv5와 같아요). 무사 무리 사이에 체력 +20.
- 모든 공격은 땅에 빨간 경고와 "!"가 먼저 떠요. 공격이 끝나면 잠깐 틈이 생겨요.
- 지면 "주로 맞은 공격"을 보여줘요. 대마왕까지 갔다가 지면 **대마왕부터** 다시 할 수 있어요.
- 별 3개: 체력 70% 이상 + 처음부터 · 별 2개: 체력 35% 이상 · 별 1개: 이김.
- 자동 확인: 구르기 없이 검만 휘두르면 대마왕에게 지고, 경고를 보고 구르면 이겨요.

## 6장 '재도전' 규칙 (레벨업·무기 강화, 2차 보스)

원작: "일주일 동안 레벨업과 무기 강화를 하고, 드래곤과 다시 싸움". 원작 그림의 아령, 검과 사슬 무기, 보라색 광선, 큰 근육 팔(6장, 작가 확인)을 썼어요.
**행동 종류, 미니게임, 재료 이름(반짝 돌, 황금 똥구슬), 모든 숫자는 [6장 설계 문서](https://claude.ai/artifact/NEH9eW3guKY5meedYomZ5t)의 제안**을 그대로 옮겼어요.
규칙은 `scenes/chapter6/growth_rules.gd`(준비)와 `scripts/battle/battle_rules.gd`(싸움)에 있어요.

**일주일 준비** (`stage6.tscn`): 1~6일 × 아침·낮·저녁 = 행동 18번. 준비 상태는 기기에 저장돼서 꺼도 이어서 해요.

| 행동 | 미니게임 | 기본 보상 |
| --- | --- | --- |
| 훈련장 | 아령 들기 (리듬 톡, 고리 8개) | 경험치 120 |
| 모험 | 구멍 속 똥 벌레 사냥 (15초) | 경험치 60, 반짝 돌 4 |
| 백성 돕기 | 무너진 집의 금을 1번부터 차례로 톡 (14초) | 경험치 40, 황금 똥구슬 1 (모두 고치면 +1) |
| 대장간 | 강화 고르기 (한 번에 최대 2단계, 항상 성공) | — |
| 작전 회의 | 드래곤 공격 4가지 중 하나 고르기 | 그 공격 경고 0.3초 일찍 |

- 미니게임을 잘하면 보상 최대 1.5배. **빠르게**를 고르면 미니게임 없이 보통 보상이에요.
- Lv 5 → 최대 15 (5→6에 100, 한 레벨마다 +20). 레벨업마다 능력치 3점을 힘·체력·민첩에 직접 나눠요.
- 힘: 검 +1, 사슬 +2 · 체력: 최대 체력 +5 (기본 50) · 민첩: 구르기 무적 +0.01초, 모으기 −0.03초 (최소 0.8초).
- 검 +1~+5 보너스 3·6·10·14·20, 사슬 무기 6·12·20·28·40. +3에서 갈림길: 빠른 검 / 무거운 검, 빙글 사슬 / 꿰뚫는 사슬.
- 6일째에 재료가 남으면 경고해요. 코인·상점·뽑기는 없어요. **"뚝뚝 두드리기" 미니게임은 이번에 넣지 않고 강화 고르기 화면만 만들었어요.**

**7일째 드래곤 2차전** (`dragon_battle.tscn`):

| 항목 | 규칙 |
| --- | --- |
| 드래곤 | 체력 1,500. 공격이 끝난 틈(쉬는 중)에만 다쳐요. 그 밖에 치면 "팅!" |
| 1단계 (1,500~1,000) | 발톱 할퀴기 15 (경고 0.8초), 보라색 광선 40 (1.0초). 공격 뒤 2초 틈 |
| 2단계 (1,000~450) | 날아올랐다가 꼬리치기 25 (0.7초). 내려온 뒤 3초 틈. 빙글 사슬로 막을 수 있어요 |
| 3단계 (450~0) | 가슴 비늘이 빛나요: 사슬 무기 1.5배 (꿰뚫는 사슬 2배). 연속 광선 40 × 3 (0.8초씩) |
| 근육 주먹 | 때리면 +5%, 아슬아슬하게 피하면 +10%. 다 차면 버튼 → 힘 × 10, 드래곤 3초 쓰러짐. 힘 20·30·40마다 팔이 굵어져요 |
| 지면 | 레벨·재료·강화는 그대로. 주로 맞은 공격을 보여주고, 준비 화면에서 능력치 다시 나누기. 3번 지면 도움 모드(체력 +50%) |
| 출발 전 | 능력치 다시 나누기, 갈림길 바꾸기(한 번), 일주일 처음부터 |
| 별 | 별 3개: 맞은 횟수 2번 이하 + 2분 30초 안 · 별 2개: 5번 이하 · 별 1개: 이김 |

자동 확인: 균형형(훈련 7, 모험 5, 돕기 3, 대장간 3 → Lv 12, 검 29, 사슬 58, 체력 130)이 설계 문서 숫자와 같고, 구르기 없이 싸우면 지고, 잘 피하면 이겨요.
이긴 뒤 "드래곤이 다시 몸을 일으켰어요"는 7장으로 잇는 **제안** 장면이에요.

## 7장 '각성과 결말' 규칙

원작: "드래곤을 완전히 물리치고, 똥 왕자가 똥의 신으로 각성".
**싸우는 도중에 각성해서 마지막 일격을 하는 흐름, 각성 효과, 숫자는 모두 제안**이에요. 각성한 모습(황금빛)도 임시예요.

| 항목 | 규칙 |
| --- | --- |
| 능력치 | 6장에서 이긴 때의 능력치를 그대로 써요 (없으면 6장 설계의 균형형) |
| 드래곤 | 체력 900. 처음부터 3단계처럼 싸워요 (발톱, 광선, 꼬리치기, 연속 광선, 빛나는 가슴 비늘) |
| 각성 게이지 | 때리면 +5%, 아슬아슬하게 피하면 +10% |
| 각성! | 드래곤 체력이 300 아래이고 게이지가 다 차면 버튼이 나와요. 12초 동안 똥의 신: 안 다치고, 공격 3배, 언제든 때리고, 사슬 무기를 바로 써요 |
| 완전히 물리치기 | 각성하지 않으면 드래곤이 체력 1로 버텨요. 각성한 힘으로만 끝낼 수 있어요 |
| 별 | 별 3개: 맞은 횟수 2번 이하 · 별 2개: 5번 이하 · 별 1개: 이김 |

## 8장 '평화' 규칙

원작: "똥 제국이 다시 평화를 찾음". 쉬어 가는 마지막 장이라 **시간 제한과 실패가 없어요**.
**할 일 세 가지와 숫자, 끝 이야기 글은 모두 제안**이에요. 1장의 마을, 불, 돔 대피소를 다시 써서 이야기를 마무리해요.

| 할 일 | 조작 |
| --- | --- |
| 무너진 집 5채 고치기 | 집을 톡톡톡 (세 번) |
| 남은 불씨 6개 끄기 | 손가락으로 쓱 (1장과 같은 쓸기) |
| 백성 8명 데려오기 | 돔 대피소의 백성을 꾹 눌러 **고친 집**까지 끌기 |

할 일을 할수록 밤하늘이 밝아지고, 모두 마치면 해가 떠요. 끝나면 별 3개, 1~8장 모은 별(24개 만점)을 보여주고 "끝" 장면 뒤 타이틀로 돌아가요.

## 귀여운 디자인 (제안)

게임 전체를 초등 고학년이 좋아할 만한 **말랑하고 귀여운 느낌**으로 바꿨어요. 원작 인물 설정(왕관·검·사슬 무기를 든 똥 왕자, 보라색 가시 드래곤, 뿔 달린 대마왕, 밤 마을, 구멍, 벽돌 성벽)과 장면 흐름은 그대로 두고, **색감과 모양만** 바꿨어요. 모두 작가 확인 전 제안이에요.

| 부분 | 바뀐 점 |
|---|---|
| 글꼴 | 둥근 한글 글꼴 **주아(Jua)** 를 넣었어요. 무료 글꼴(SIL OFL)이라 앱에 넣어도 돼요. 라이선스는 `assets/fonts/OFL.txt` |
| 색 | 크림·분홍·민트·하늘·연보라·레몬 파스텔. 밤 장면은 검정 대신 보랏빛 밤 |
| 버튼 | 통통한 젤리 버튼 (아래 두꺼운 테두리, 누르면 쏙 들어가요), 글자에 테두리 |
| 창·표시줄 | 분홍 테두리 크림 창, 아래가 둥근 반투명 표시줄, 둥근 체력 막대 |
| 인물 | 반짝이는 큰 눈, 볼터치, 웃는 입. 똥 왕자는 밀크초코색, 드래곤은 연보라. 적은 심술 난 눈썹으로 "귀여운 악당" |
| 배경 | 웃는 해님·달님, 몽글 구름, 꽃, 반짝이. 불꽃·대포·바위에도 작은 얼굴 |
| 타이틀 | 하늘·언덕 배경에 손 흔드는 똥 왕자, 떠다니는 하트 |

색과 버튼 모양은 `scripts/art/cute.gd` **한 곳**에 모아 두었어요. 여기 숫자만 고치면 게임 전체가 같이 바뀌어요.

화면 캡처는 아래처럼 다시 만들 수 있어요 (창이 뜨는 모드, 헤드리스 아님).

```bash
godot --path . -s tests/screenshots.gd -- ./shots
```

## PC에서 실행하고 확인하기

1. [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/)을 내려받아요. (표준 버전, .NET 아님)
2. Godot를 열고 **가져오기(Import)** 를 눌러 이 폴더의 `project.godot`를 골라요.
3. 오른쪽 위 **▶ (F5)** 를 눌러요.
4. 확인할 것
   - 가로로 긴 창에 「똥제국의 위기」 제목이 통통 튀어요. **시작하기**를 눌러요.
   - 이야기 장면 3장이 나와요. 화면을 누르면 넘어가고, 마지막 장면에서 누르면 시작해요.
   - 백성(막대 사람)을 마우스로 끌어서 오른쪽 아래 **대피소**에 놓으면 "구한 백성"이 올라가요.
   - 불 위로 백성을 끌면 막혀요. 빈 곳에서 마우스를 누른 채 불 위를 쓱 지나가면 불이 꺼져요.
   - 20초쯤 지나면 드래곤이 고개를 내리고 입을 벌려요. 노랗게 빛나는 코를 누르면 "에취!"가 나와요.
   - 땅에 분홍 점선이 보이면 곧 보라색 줄기가 와요. 맞으면 하트가 줄어요.
   - 12명 이상 구하고 시간이 끝나거나, 15명을 다 구하면 드래곤이 날아가고 별 결과가 나와요.
   - 하트를 다 잃으면 "아쉬워요!" 창에 팁이 나오고, 8명 이상 구했었다면 **중간부터** 버튼이 있어요.

## 안드로이드 폰에서 실행하기

1. Godot 메뉴 **편집기 → 편집기 설정 → 내보내기 → Android**에서 Java SDK(OpenJDK 17)와 Android SDK 경로를 넣어요.
   자세한 방법은 [공식 문서](https://docs.godotengine.org/ko/4.x/tutorials/export/exporting_for_android.html)를 봐요.
2. **편집기 → 내보내기 템플릿 관리**에서 4.3 템플릿을 내려받아요.
3. 폰에서 **개발자 옵션 → USB 디버깅**을 켜고 PC에 연결해요.
4. 오른쪽 위에 생기는 **안드로이드 아이콘(원격 실행)** 을 누르면 폰에서 바로 실행돼요.
   APK 파일이 필요하면 **프로젝트 → 내보내기 → Android → 프로젝트 내보내기**를 눌러요.

> 디버그 실행은 Godot가 만드는 디버그 키로 서명돼요. 구글 플레이에 올릴 때는 따로 릴리스 키가 필요해요.
> 키 파일(`*.keystore`)은 저장소에 올리지 않도록 `.gitignore`에 넣어 두었어요.
