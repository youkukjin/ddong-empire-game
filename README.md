# 똥제국의 위기

직접 만든 동화책 「똥제국의 위기」를 바탕으로 한 어린이용 안드로이드 게임이에요.
엔진은 **Godot 4.3 (GDScript)** 를 써요.

## 지금 들어 있는 것

| 항목 | 내용 |
| --- | --- |
| 화면 | **가로 화면**(1280×720 기준). 비율이 다른 기기에서는 위아래나 양옆에 여백이 생겨요 |
| 조작 | 터치 (PC에서는 마우스가 터치처럼 동작해요) |
| 타이틀 화면 | 제목과 **시작하기**, **장 고르기** 버튼. 1장을 별 3개로 깨면 **어려움 모드** 버튼이 나타나요 |
| 장 고르기 | 1~8장 칸. 깬 장의 다음 장이 열리고, 칸에 최고 별이 보여요 |
| 1장 '등장' | 이야기 장면 → 대피 플레이 → 드래곤 퇴장 → 결과 화면 → 2장으로 |
| 2장 '준비' | 연습 네 가지(아령 들기, 검, 사슬 무기, 구르기) → 결과 화면 → 3장 예고 |
| 3장 '구멍 탐험' | 굴 속 달리기(뛰기, 숙이기, 갈림길 고르기) → 본거지 입구 → 결과 화면 |
| 안드로이드 | 내보내기 설정(`export_presets.cfg`) 포함, 뒤로 가기 버튼 = 멈춤 |

그림은 아직 없어서 모두 **임시 도형**이에요 (보라색 드래곤, 막대 사람 백성, 불, 돔 대피소, 밤 배경).

## 1장 '등장' 규칙

[1장 기획안](https://claude.ai/artifact/WJhDciA1xNwsJyKAkchmTw)대로 만들었어요. 숫자는 모두 `scenes/chapter1/stage1_rules.gd` 한 파일에 모여 있어서 거기만 고치면 바뀌어요.

| 항목 | 규칙 |
| --- | --- |
| 목표 | 3분 안에 백성 15명 중 **12명 이상**을 돔 대피소로 |
| 백성 구하기 | 백성을 누른 채 돔까지 **끌기**. 불 위로는 지나갈 수 없어요 |
| 불 끄기 | 빈 곳에서 손가락으로 **쓱 쓸기**. 한 번에 3개 이상 끄면 **콤보 별 +1** |
| 드래곤 코 | 15초마다 드래곤이 입을 벌려요. 코가 빛나는 **1.5초 안에 톡** → "에취!" 하고 물러나요 |
| 보라색 줄기 | 땅에 경고 점선이 먼저 보이고 줄기가 나가요. 지나간 자리에 불이 붙어요 |
| 하트 | 3개. 백성이 줄기에 맞거나, 코를 놓치면 1개 줄어요 (코를 놓치면 백성 1명이 겁을 먹고 도망가요) |
| 불 번짐 | 5초 동안 안 끄면 옆으로 번져요 |
| 난이도 | 처음 20초 연습(줄기 없음, 불 2개) → 초반(4초마다, 1초 전 점선, 불 3개) → 8명 구한 뒤 후반(3초마다, 0.7초 전 점선, 훑는 줄기, 불 5개) |
| 별 | 별 3개: 15명 + 하트를 하나도 안 잃음 · 별 2개: 14~15명 · 별 1개: 12~13명 |
| 실패 | 하트 0개, 또는 시간이 끝났는데 12명 미만. 팁 한 줄을 보여 줘요 |
| 중간 지점 | 8명을 구한 순간 저장. 실패하면 **중간부터**로 8명, 하트 3개에서 다시 시작 |
| 도움 켜기 | 3번 연속 실패하면 권해요. 켜면 경고 점선이 1.5초 전에 나와요 |
| 어려움 모드 | 별 3개로 깨면 열려요. 하트 1개, 2분 30초 |
| 멈추기 | 오른쪽 위 **II** 버튼 → 계속 / 다시 하기 / 처음으로 |

### 기획안에 없어서 새로 정한 것 (제안)

- 첫 큰 입은 연습 20초가 끝날 때 나와요. 연습 중에 하트를 잃지 않게 하려고요.
- 줄기에 맞은 백성은 1초 동안 어질어질해서 끌 수 없어요.
- 중간부터 다시 할 때 남은 시간이 1분보다 적으면 1분으로 채워 줘요. 중간부터 한 판은 별 3개가 안 돼요.
- 도망간 백성이 4명이 되면 12명을 채울 수 없어서 바로 실패로 끝나요.
- 이야기 장면 글, 드래곤이 날아가는 퇴장, 똥 왕자가 다짐하는 예고 장면은 기획안의 (제안)을 글로 옮긴 거예요. 작가 확인 전이에요.
- 기록(최고 별, 2장 열림, 어려움 모드 열림)은 기기 안 `user://save.cfg`에 저장돼요.

## 2장 '준비' 규칙

원작 챕터 구성표에는 "똥 왕자가 드래곤을 물리치려고 준비함"까지만 있어서, **연습 종류와 숫자는 모두 제안**이에요.
아령은 원작 그림에 여러 번 나와서 첫 연습으로 골랐어요. 숫자는 `scenes/chapter2/stage2_rules.gd`에 모여 있어요.

| 연습 | 조작 | 통과 / 별 2개 / 별 3개 |
| --- | --- | --- |
| 아령 들기 | 줄어드는 고리가 가운데 원에 맞을 때 **톡** (±0.12초 2점, ±0.25초 1점, 고리 12개) | 12 / 17 / 21점 |
| 검 연습 | 25초 동안 튀어나온 표적을 **톡**. 테두리가 두꺼운 단단한 표적은 두 번 | 12 / 18 / 24개 |
| 사슬 무기 연습 | **꾹 눌러** 힘을 모으고(1.7초), 표적이 초록 줄 위에 올 때 **떼기**. 6번 | 3 / 4 / 6번 |
| 구르기 연습 | 굴러오는 공에 "!"가 뜨면 **쓱 쓸어서** 구르기. 무적 0.4초. 공 10개 | 6 / 8 / 10개 |

- 연습마다 안내 창 → 시작 → 결과예요. 통과 못 하면 그 연습만 다시 해요. 통과한 연습도 "다시 연습"으로 별을 더 받을 수 있어요.
- 장 별: 네 연습 별을 더해서 11개 이상 별 3개, 8개 이상 별 2개, 나머지 별 1개.
- 여기서 익힌 조작(탭 = 검, 길게 눌렀다 떼기 = 사슬 무기, 쓸기 = 구르기)은 5~7장 싸움에서 그대로 써요. (제안)
- 모으기 1.7초와 무적 0.4초는 [6장 설계](https://claude.ai/artifact/NEH9eW3guKY5meedYomZ5t)의 시작 능력치(민첩 10) 값이에요.
- 이야기 글과 3장 예고 글은 제안이에요. 작가 확인 전이에요.

## 3장 '구멍 탐험' 규칙

원작: "일주일 후 준비를 마치고, 수상한 구멍으로 들어가 드래곤의 본거지를 찾음". 원작 그림에 왕자가 검을 들고 구멍에 들어가는 장면이 있어요.
**달리기 방식, 장애물, 갈림길의 보라색 자국(드래곤이 지나간 흔적), 숫자는 모두 제안**이에요. 숫자는 `scenes/chapter3/stage3_rules.gd`에 있어요.

| 항목 | 규칙 |
| --- | --- |
| 달리기 | 왕자가 저절로 달려요. 굴 4구간, 구간마다 빨라져요 (300 → 420) |
| 톡 (또는 위로 쓱) | 뛰어서 바위와 구덩이를 넘어요. 높이 떠 있는 반짝이는 돌도 뛰어야 먹어요 |
| 아래로 쓱 | 숙여서 낮은 천장 밑을 지나가요 |
| 갈림길 | 앞 3구간 끝마다 위·아래 굴. 3초 전부터 보여요. **보라색 자국** 쪽으로 쓸어요. 틀리거나 안 고르면 막다른 길이라 10초를 잃어요 |
| 하트 | 3개. 장애물에 부딪히면 1개 줄고 1초 동안은 다시 안 다쳐요 |
| 시간 | 1분 15초 (쉬지 않고 달리면 약 54초) |
| 별 | 별 3개: 하트 그대로 + 갈림길 모두 맞힘 + 반짝이는 돌 70% 이상 · 별 2개: 하트 2개 이상 · 별 1개: 도착 |
| 실패 | 하트 0개, 또는 시간 끝 |

굴 모양은 판마다 달라져요. 이야기 글과 4장 예고 글("본거지 아래를 단단한 성벽이 막고 있었어요")은 제안이에요.

## 폴더 구조

```
project.godot                 프로젝트 설정 (가로 화면, 터치, 모바일 렌더러)
export_presets.cfg            안드로이드 내보내기 설정
scenes/title/                 타이틀 화면, 장 고르기 화면
scenes/chapter1/stage1.tscn   1장 '등장' 스테이지 (진행, 터치, 화면 위 표시, 창)
scenes/chapter1/stage1_rules.gd  1장 규칙과 숫자
scenes/chapter1/              드래곤, 백성, 불, 줄기, 밤 배경, 달 타이머·하트·별 그림
scenes/chapter2/              2장 '준비' 스테이지와 규칙
scenes/chapter3/              3장 '구멍 탐험' 스테이지와 규칙
scripts/stage_base.gd         2장부터 함께 쓰는 스테이지 뼈대 (이야기 장면, 멈추기, 결과 창, 다음 장)
scripts/gesture.gd            탭 / 쓸기 / 길게 누르기 나누기
scripts/chapters.gd           장 목록 (이름은 원작 챕터 구성표 그대로)
scripts/art/                  임시 그림: 똥 왕자, 장마다 배경
scripts/game_session.gd       실행 중에만 기억하는 것 (어려움 모드, 중간 지점, 도움 켜기)
scripts/save_data.gd          기기에 남는 기록
tests/                        자동 확인
```

## PC에서 실행하고 확인하기

1. [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/)을 내려받아요. (표준 버전, .NET 아님)
2. Godot를 열고 **가져오기(Import)** 를 눌러 이 폴더의 `project.godot`를 골라요.
3. 오른쪽 위 **▶ (F5)** 를 눌러요.
4. 확인할 것
   - 가로로 긴 창에 「똥제국의 위기」 제목이 통통 튀어요. **시작하기**를 눌러요.
   - 이야기 장면 3장이 나와요. 화면을 누르면 넘어가고, 마지막 장면에서 누르면 시작해요.
   - 백성(막대 사람)을 마우스로 끌어서 오른쪽 아래 **대피소**에 놓으면 "구한 백성"이 올라가요.
   - 불 위로 백성을 끌면 막혀요. 빈 곳에서 마우스를 누른 채 불 위를 쓱 지나가면 불이 꺼져요.
   - 20초쯤 지나면 드래곤이 고개를 내리고 입을 벌려요. 노랗게 빛나는 코를 누르면 "에취!"가 나와요.
   - 땅에 분홍 점선이 보이면 곧 보라색 줄기가 와요. 맞으면 하트가 줄어요.
   - 12명 이상 구하고 시간이 끝나거나, 15명을 다 구하면 드래곤이 날아가고 별 결과가 나와요.
   - 하트를 다 잃으면 "아쉬워요!" 창에 팁이 나오고, 8명 이상 구했었다면 **중간부터** 버튼이 있어요.

### 자동 확인 (선택)

```bash
godot --headless --path . --import          # 처음 한 번
godot --headless --path . -s tests/smoke_test.gd
godot --headless --path . -s tests/stage1_test.gd
godot --headless --path . -s tests/stage2_test.gd
godot --headless --path . -s tests/stage3_test.gd
```

확인마다 마지막에 `모든 확인 통과`가 나오면 성공이에요.
`stage1_test.gd`는 규칙 계산(시간, 하트, 별, 중간 저장, 난이도)과 실제 터치(끌기, 불 막힘, 쓸기 콤보, 코 누르기, 줄기 맞기), 승리·실패 흐름을 확인해요.

## 안드로이드 폰에서 실행하기

1. Godot 메뉴 **편집기 → 편집기 설정 → 내보내기 → Android**에서 Java SDK(OpenJDK 17)와 Android SDK 경로를 넣어요.
   자세한 방법은 [공식 문서](https://docs.godotengine.org/ko/4.x/tutorials/export/exporting_for_android.html)를 봐요.
2. **편집기 → 내보내기 템플릿 관리**에서 4.3 템플릿을 내려받아요.
3. 폰에서 **개발자 옵션 → USB 디버깅**을 켜고 PC에 연결해요.
4. 오른쪽 위에 생기는 **안드로이드 아이콘(원격 실행)** 을 누르면 폰에서 바로 실행돼요.
   APK 파일이 필요하면 **프로젝트 → 내보내기 → Android → 프로젝트 내보내기**를 눌러요.

> 디버그 실행은 Godot가 만드는 디버그 키로 서명돼요. 구글 플레이에 올릴 때는 따로 릴리스 키가 필요해요.
> 키 파일(`*.keystore`)은 저장소에 올리지 않도록 `.gitignore`에 넣어 두었어요.

- 앱 패키지 이름은 임시로 `com.ddongempire.game`이에요. 플레이 스토어에 올리기 전에 정하면 돼요.
